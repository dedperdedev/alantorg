# alantorg

## Технологии

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Локальная разработка

```sh
git clone https://github.com/dedperdedev/alantorg.git
cd alantorg
npm i
npm run dev
```

## Сборка

```sh
npm run build
npm run preview
```

## Деплой

Проект настроен на деплой в GitHub Pages через GitHub Actions. При пуше в ветку `main` приложение собирается и публикуется по адресу:

**https://dedperdedev.github.io/alantorg/**

В настройках репозитория (Settings → Pages) должен быть выбран источник **GitHub Actions**.
